# The-Big-B-A-M-Theory

Project Description

Our project is going to be working on a website named "X's & O's".
It is going to be a college dating website where you need a valid college email to log in and once you match with someone there is going to be a link for both people to play a game of tik tac toe before the conversation as an icebreaker while also having a block and report button with the basic chat structure.

# Main Features

The planned features of the website are this:

College email sign in to make sure they are students.

Profiles that each person makes according to their preferences.

A matching system that makes it so students play a game as an ice breaker.

A basic chat structure that allows the students to chat after the game.

A simple and user-friendly website design.

We may find features we want to change, get rid of or add as we progress.
